# Бюджет-бот в Telegram

Один бот для всего:
- **проверка перед покупкой** — пишете «150000 обед», бот отвечает ✅ / ⚠️ / ⏳ / ❌;
- **учёт гибких трат** с недельными лимитами и месячным лимитом на одежду;
- **21:00** — напоминание выгрузить MoneyLover на Google Диск;
- **21:30** — бот сам берёт экспорт, вносит траты и присылает итог дня. Если выгрузки нет, бот ничего не присылает;
- **воскресенье, 20:45** — итог недели;
- **2-го числа, 10:00** — итог месяца по плану экономии (13 статей);
- **список желаний** с правилом 48 часов и напоминанием.

Бот работает в **Google Apps Script** на вашем Google-аккаунте: свой сервер не нужен, всё бесплатно. Данные хранятся в таблице «Бюджет-бот — данные» на вашем Диске.

## Установка (≈10 минут, один раз)

### 1. Создайте бота
1. В Telegram откройте **@BotFather** → `/newbot`.
2. Введите имя (например, «Мой бюджет») и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456:ABC...`. Никому его не отправляйте.

### 2. Создайте проект Apps Script
1. Откройте https://script.google.com под аккаунтом, где лежат экспорты MoneyLover (**shav554482@gmail.com**).
2. **Новый проект** → назовите «Бюджет-бот».
3. Удалите всё из `Code.gs` и вставьте содержимое файла [`Code.gs`](Code.gs) из этой папки.
4. ⚙️ **Настройки проекта**:
   - включите «Показывать файл манифеста appsscript.json»;
   - **Часовой пояс:** `(GMT+05:00) Tashkent`.
5. Откройте `appsscript.json` в редакторе и замените его содержимое на файл [`appsscript.json`](appsscript.json).
6. ⚙️ **Настройки проекта → Свойства скрипта → Добавить свойство:**
   - имя: `TOKEN`
   - значение: токен от BotFather.

### 3. Веб-приложение (больше не нужно)
Бот сам забирает сообщения из Telegram раз в минуту, поэтому разворачивать веб-приложение не обязательно. Шаги ниже можно пропустить.

<details><summary>Старый способ</summary>

1. **Развернуть → Новое развертывание** → тип **Веб-приложение**.
2. «Выполнять как»: **Я**. «Кто имеет доступ»: **Все**.
3. **Развернуть** → разрешите доступ: Google спросит разрешения на Диск, таблицы и внешние запросы.

4. Нажмите **Развернуть → Управление развертываниями**, скопируйте **URL веб-приложения**: он заканчивается на `/exec`.
5. ⚙️ **Настройки проекта → Свойства скрипта** → добавьте `WEBAPP_URL` = этот адрес.

</details>

### 4. Запустите настройку
1. В редакторе выберите функцию **`setup`** → **Выполнить**.
2. В журнале должно появиться `deleteWebhook: {"ok":true...}` и «Готово».

### 5. Начните
Откройте своего бота в Telegram и нажмите **/start**. Бот запомнит ваш чат: отвечать он будет **только вам**.

## Как пользоваться

| Что написать | Что будет |
|---|---|
| `150000 обед` / `150 обед` / `1,2 млн наушники` / `300к uzum` | Проверка покупки. Категорию бот угадает по слову или спросит |
| ✅ Купил — записать | Трата записана |
| 🛍 В список желаний | Через 48 часов бот спросит ещё раз |
| 📊 Сегодня | Сколько можно сегодня и траты за день |
| 📅 Неделя | Неделя по категориям |
| 🛍 Список желаний | Отложенные покупки |
| ⚙️ Лимиты, `/limit cafe 400000` | Посмотреть или изменить лимиты |
| `/undo` | Удалить последнюю ручную запись |
| `/import` | Забрать сегодняшний экспорт MoneyLover сразу |
| `/month` | Итог прошлого месяца по плану |

**Каждый вечер:** MoneyLover → «Пластик» → Экспорт → период «Этот месяц» → Google Диск. Остальное бот делает сам.

## Лимиты по умолчанию
| Категория | Лимит |
|---|---:|
| Кафе и алкоголь | 360 000 в неделю |
| Маркетплейсы | 380 000 в неделю |
| Гаджеты, духи, перекусы | 230 000 в неделю |
| Прочее / наличные | 460 000 в неделю |
| Одежда | 2 500 000 в месяц |

## Если что-то не работает
- **Бот молчит:** снова запустите `setup`. Если код меняли, сделайте **Развернуть → Управление развертываниями → Изменить → Новая версия**.
- **Нет итога в 21:30:** проверьте, что экспорт сделан сегодня и в его названии есть «MoneyLover» и «Пластик».
- **Журнал ошибок:** Apps Script → «Выполнения».
