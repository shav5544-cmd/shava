# Шпаргалка по метрикам взыскания / Undirish metrikalari bo‘yicha qisqa qo‘llanma

## 📈 Раннее взыскание (1–90 дней) / Erta undirish (1–90 kun)

| Метрика / Metrika | Формула / Formula | Кратко / Qisqacha |
|---|---|---|
| **Inflow Rate** | `Inflow = OD(бакет 0 на начало месяца, перешедший в 1–30 в течение месяца) / OD(бакет 0 на начало месяца)` | Только **ОД**, база — бакет 0 на начало месяца. |
| **Cure Rate 1–30** | `Cure(1–30) = Погашено OD из бакета 1–30 (LIFO) / OD бакета 1–30 на начало` | Доля cured из 1–30. |
| **Cure Rate 31–60** | `Cure(31–60) = Погашено OD из бакета 31–60 (LIFO) / OD бакета 31–60 на начало` | Доля cured из 31–60. |
| **Cure Rate 61–90** | `Cure(61–90) = Погашено OD из бакета 61–90 (LIFO) / OD бакета 61–90 на начало` | Доля cured из 61–90. |
| **Cure Rate накопительный 1–90** | `Cure(1–90)_cum = 1 - (1 - Cure(1–30)) × (1 - Cure(31–60)) × (1 - Cure(61–90))` | Накопительный cure через цепочку бакетов. |
| **Roll Rate** | `Roll(i→j) = OD, перешедший из бакета i в j / OD бакета i на начало` | Считается по переходам между бакетами. |
| **Flow Rate** | `Flow Rate = Inflow Rate × (1 - Cure(1–90)_cum)` | Поток в более глубокую просрочку после учета cure. |

## 🛑 Позднее взыскание (NPL 90+) / Kechki undirish (NPL 90+)

| Метрика / Metrika | Формула / Formula | Кратко / Qisqacha |
|---|---|---|
| **Recovery Rate 91–180** | `Recovery(91–180) = Cash collected по бакету 91–180 / OD бакета 91–180 на начало` | `Cash collected = ОД + проценты + штрафы/комиссии`. |
| **Recovery Rate 181–360** | `Recovery(181–360) = Cash collected по бакету 181–360 / OD бакета 181–360 на начало` | Аналогично, по бакету 181–360. |
| **Recovery Rate 361+** | `Recovery(361+) = Cash collected по бакету 361+ / OD бакета 361+ на начало` | Для 361+ **цессии и списания не учитываются**. |
| **NPL 90+** | `NPL 90+ = OD(бакеты 90+) / OD(активный портфель)` | Только активный портфель, только **ОД**. |

## 💳 Direct Debit / Avtoto‘lov (Direct Debit)

| Метрика / Metrika | Формула / Formula |
|---|---|
| **Доля погашений через direct debit** | `DD share(bucket) = Погашения через direct debit в бакете / Все погашения в бакете` |

Бакеты / Bucketlar: **0+**, **1–30**, **31–60**, **61–90**, **91–180**, **181+**.

## 📞 Колл-центр (операторские кампании) / Koll-markaz (operator kampaniyalari)

| Метрика / Metrika | Формула / Определение |
|---|---|
| **Penetration rate** | Доля клиентской базы, охваченной обзвоном за период: `Уникальные клиенты с попыткой контакта / Целевая база`. |
| **SPIN** | Среднее число попыток дозвона на 1 клиента: `Всего исходящих попыток / Кол-во уникальных клиентов в базе обзвона`. |
| **Contact rate (CR)** | `CR = Кол-во успешных контактов / Кол-во попыток дозвона`. |
| **RPC rate** | `RPC = Кол-во RPC (контакт с правильным клиентом) / Кол-во успешных контактов`. |
| **PTP rate** | `PTP = Кол-во обещаний оплаты (PTP) / Кол-во RPC`. |
| **KP rate** | `KP = Кол-во выполненных обещаний (kept PTP) / Кол-во обещаний оплаты (PTP)`. |
| **Utilization** | `Utilization = Время разговора + постобработка / Оплаченное рабочее время операторов`. |
| **Occupancy** | `Occupancy = Время разговора + постобработка / Время присутствия в линии (ready+talk+ACW)`. |

## 🚗 Выездное взыскание / Sayyor undirish

| Показатель / Ko‘rsatkich | Формула / Formula |
|---|---|
| **Выездов на клиента в месяц** | `Кол-во выездов за месяц / Кол-во уникальных клиентов в выездной работе`. |
| **Выездов на сотрудника в день** | `Кол-во выездов / (Кол-во сотрудников × кол-во рабочих дней)`. |
| **Нагрузка на 1 ПШЕ** | `Объем портфеля (клиенты или OD) в выездной работе / Кол-во ПШЕ`. |

## ⚖️ Судебное взыскание / Sud orqali undirish

| Показатель / Ko‘rsatkich | Формула / Formula |
|---|---|
| **Доля СИП по бакетам** | `Доля СИП(bucket) = OD дел на стадии СИП в бакете / OD соответствующего бакета`. |
| **Эффективность суд. взыскания (1, 2, 3 года)** | `Eff_y = Взыскано за y лет по судебным кейсам / OD, переданный в суд (когорта)`; где `y ∈ {1,2,3}`. |

## ⚠️ Ключевые правила / Asosiy qoidalar

- Во всех балансах используется только **Основной долг (ОД)**.
- Для **Recovery Rate** используется `Cash collected = ОД + проценты + штрафы/комиссии`.
- Период анализа: **январь 2025 – май 2026**, помесячно.
- Метод учета просрочки: **LIFO**.
